# 一念 · 禅心祈福（体验版）

这是一个纯静态 HTML/CSS/JavaScript 网页原型，可部署到 GitHub Pages 或 Vercel。

## 文件
- `index.html`：页面结构
- `style.css`：响应式样式
- `app.js`：互动和本地演示数据

## 本地预览
直接用浏览器打开 `index.html` 即可。

## 重要说明
- 当前为体验演示版，不接入真实微信支付或支付宝。
- “开启演示会员”不会扣款，只在当前浏览器写入演示状态。
- 数据保存在浏览器 localStorage，清除浏览器数据或更换设备可能丢失。
- 请勿在测试版填写身份证、银行卡等敏感信息。
- 正式上线前需要补充隐私政策、用户协议、退款规则、后端账号和订单验证等。
- 祈福内容仅作文化与心灵陪伴，不预测命运，也不承诺现实结果。
